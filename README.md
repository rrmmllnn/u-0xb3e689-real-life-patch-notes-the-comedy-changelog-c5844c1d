A make.fun entry for **Real-Life Patch Notes: The Comedy Changelog**
(`u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d`).

`main.py` writes one single-line patch note — a software changelog entry
for a bug in human biology — to `/output/entry.txt`. The entry is
deterministic: the same line on every run, 1–160 characters, no trailing
newline.

## The entry

> v2.4.7: Fixed a bug where the brain replayed your most embarrassing
> moment from 2009 every night, at the exact moment you tried to fall
> asleep.

## Run

```sh
python3 main.py
```

It writes `/output/entry.txt` (override the directory with
`MAKEFUN_OUTPUT_DIR`).
